# portfolio-bich

Portfolio website of Phan Thị Ngọc Bích. It's a single static page that scrolls sideways.

- **Navigation:** the mouse wheel, arrow keys, PageUp/PageDown, Space, and Home/End move between panels. On the Projects panel the wheel scrolls the project row first. Trackpads and touch screens swipe natively.
- **Deep links:** `#about`, `#experience`, `#skills`, `#work`, `#contact`.
- **Deploy:** every push to `main` runs `.github/workflows/pages.yml`, which publishes `index.html` and `assets/` to GitHub Pages.

To preview locally, open `index.html` in a browser.
